# Data and source provenance

`pyspats/data/wheat.csv` is an unmodified CSV export of `wheatdata` from the
supplied R SpATS 1.0-20 archive (2026-05-17 package date). The loader adds
categorical R/C coordinate copies. R's dataset documentation describes a
South Australian wheat trial: 330 plots, 107 varieties, three replicates,
22 rows by 15 columns. Row/column codes describe sowing and trimming patterns.

R credits Gilmour, Cullis and Verbyla (1997), *Accounting for Natural and
Extraneous Variation in the Analysis of Field Experiments*, Journal of
Agricultural, Biological, and Environmental Statistics 2, 269–293, and Kevin
Wright's `agridat` collection. The original documentation is in the supplied
archive at `SpATS/man/wheatdata.Rd`. Distributed here with the GPL-derived port.

`tests/reference/field.csv` is synthetic: generated solely by the fixed-seed R
script `tests/reference/generate.R`. All `*_fitted.csv`, `*_components.csv` and
`*_stats.csv` reference outputs are generated by R, never by Python. The script
also exports the real wheat data. It requires R SpATS version 1.0-20, checks
that version, and can regenerate the fixtures from the repository root.

The bundled sorghum CSV and historical example outputs predate this rewrite.
Their full experimental provenance has not been independently established;
they are examples, not substitutes for the R-generated regression fixtures.

R source authors: María Xosé Rodríguez-Álvarez, Martin Boer, Paul Eilers,
with Fred van Eeuwijk contributing. The Python tensor basis and SAP equations
are translations of that source. The package retains GPL licensing and includes
`LICENSE`; the original archive is preserved under `rSpATS/`.

For the sorghum regression reference, blank genotype identifiers are explicitly
parsed as missing in R and incomplete predictor rows are removed before fitting.
This aligns the Python input policy; R's default blank-string parsing would
otherwise introduce an extra genotype with one observed plot.
