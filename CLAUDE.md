# Repository guidance

Use [AGENTS.md](AGENTS.md) for development instructions and statistical
invariants. [README.md](README.md) documents the current API.

The 2025 implementation and its claims about approximate effective dimensions,
three-block PSANOVA, fixed-genotype heritability and CHOLMOD-only fitting were
replaced. Do not restore those assumptions. See
[the methodology review](docs/methodology-review.md) and
[the migration notes](docs/migration.md).
